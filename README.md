## Quy ước đang áp dụng
- VN-first
- Markdown links là chuẩn chính
- Mỗi chủ đề chỉ có 1 canonical doc
- Supporting docs không được cạnh tranh nội dung với canonical doc

## Cách đọc nhanh
1. Bắt đầu từ [Knowledge Base chính](SHUNCOM%20RULR%20Knowledge%20Base/README.md) nếu cần nắm hệ thống theo domain.
2. Đọc nhóm tài liệu trong `docs/` nếu cần trace nguồn BA, flow, requirements, và mapping.
3. Cập nhật trực tiếp canonical doc khi nội dung chủ đề thay đổi.
